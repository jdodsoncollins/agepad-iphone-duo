# Image provenance

`steam-library-iphone-17-pro-max.png` uses a user-provided phone capture of
AgePad's Steam library. It contains no gameplay, account identity, password or
sign-in QR code. The screenshot content is retained, with proportional scaling
and clipping at the device frame's screen boundary.

The landscape silver iPhone 17 Pro Max frame is from the Apple device artwork
included in [Koubou 0.20.0](https://github.com/bitomule/Koubou/tree/v0.20.0).
The framing tool and unframed source remain outside the public repository.

`technical-approach.svg` is the editable source for the architecture diagram;
`technical-approach.png` is its raster export for clients without Mermaid support.

Other images in this directory were inherited from upstream's iPad documentation.
